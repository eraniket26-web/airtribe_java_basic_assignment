Project description

This project is a simple command-line application called as Student & Course Management System. It allows users to manage students and courses by providing functionalities such as adding students, adding courses, enrolling students in courses, and displaying the list of students and courses. The application is built using Java and follows a basic object-oriented programming approach. It uses classes to represent students and courses, and it provides methods to perform various operations related to student and course management. The application is designed to be user-friendly and can be easily extended with additional features in the future.


How to compile and run

To compile and run the Student & Course Management System application, follow below steps:

1. Make sure you have java installed in your system .
2. Download the source code of the application and save it in a directory.
3. Run Main.java file to start the application. You can use the command line or an IDE to run the application.
4. Follow the prompts in the command line to interact with the application and manage students and courses.
5. Provide input as and when application prompts you to perform various operations such as adding students, adding courses, enrolling students in courses, and displaying the list of students and courses.
6. To exit the application, you can use the exit command by pressing '0' when prompted for an option.
